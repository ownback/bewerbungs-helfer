# Lokales Profil

Hier entstehen beim ersten Durchlauf:

- `master-profile.md` – das bestätigte Master-Profil
- `import/` – optional vom Nutzer bereitgestellte Lebensläufe, Zeugnisse und Zertifikate
- `assets/` – lokale Bild- und Dokumentdateien

Der gesamte Inhalt ist gitignoriert. Das Repository startet ohne Profil-, Job- oder Bewerbungsdaten.
