# Datenschutz und Grenzen

## Lokal zuerst

Das Master-Profil, Bewerbungsmappen und Nachweise bleiben in diesem Repository auf dem lokalen Rechner. Die Ordner `profile/` und `applications/` sind gitignoriert. In Git gehören ausschließlich Workflow, Dokumentation und Skill-Ressourcen.

## Keine Beispieldaten im Repository

Das Repository enthält bewusst kein Demo-Profil, keinen Demo-Job und keine Demo-Bewerbung. Ein frischer Clone beginnt leer. Der Agent fragt beim ersten Start nach den Angaben des Nutzers.

## Keine automatische Außenwirkung

Der Bewerbungshelfer darf:

- öffentliche Stellenanzeigen lesen,
- öffentliche Unternehmenskontakte recherchieren,
- Dokumente vorbereiten,
- eine E-Mail oder ein Anschreiben als Entwurf formulieren.

Der Bewerbungshelfer darf nicht ohne ausdrückliche Freigabe:

- eine Bewerbung absenden,
- ein Bewerbungsportal ausfüllen,
- Dateien in einem fremden System hochladen,
- persönliche Daten an einen weiteren Dienst übertragen.

## Quellen und Belege

Jede übernommene Anforderung aus einer Stellenanzeige bekommt eine Quelle: Stellen-URL, Abrufdatum und wörtlicher Beleg. Kontaktdaten werden nur übernommen, wenn sie in der Anzeige oder auf einer öffentlichen Unternehmensseite stehen. Unsichere Angaben bleiben sichtbar als offen markiert.
